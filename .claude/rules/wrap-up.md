# 收尾流程

触发：一个任务或一次会话结束时（也可以用 `/wrap-up`）。

1. 有没有未提交的改动？有就问 Logan 是提交还是保留。
2. 更新 `docs/roadmap.md`：
   - 勾选本次完成的项
   - 更新"当前位置"（阶段、里程碑、下一步要做的具体一项）
   - 有功能完成的话，在"完成记录"里加一行（日期、内容、PR、备注）
3. 有没有新的决定还没写进 ADR？有就提醒 Logan，或按 `adr-workflow.md` 写。
4. Logan 有没有就同一类问题纠正你两次以上？有就建议把这条规则加进 `CLAUDE.md`（只提建议，由 Logan 确认）。
5. 给 Logan 一段简短总结：完成了什么、没做完的部分及原因、下一步。

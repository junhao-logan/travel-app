# ADR-0005：线上对象存储
- 状态：已采纳
- 日期：2026-11-22
- 背景：图片站的长期成本主要在存储和下载流量（出口流量 / egress）。照片"存一次、被看很多次"，流量费通常远高于存储费。本地开发用 MinIO（S3 兼容 API），线上需要选一家服务商。
- 选项：
  - A：Cloudflare R2：S3 兼容 API，出口流量免费，自带 Cloudflare CDN，有免费额度 / 功能和生态比 S3 少，部分细节（上传大小限制、删除保护）需在实现时验证
  - B：AWS S3 + CloudFront：行业标准、功能最全、生态最大 / 出口流量收费，图片站有人气后这是最大的账单
- 决定：A（Cloudflare R2）。
- 理由：
  1. 按选型原则：最主流的是 S3，但它的流量费是图片站的主要成本，所以先用低价的 R2，并保证可以方便地换回 S3（见下方"切换计划"）。
  2. 出口流量免费，成本不随浏览量增长。
  3. S3 兼容，开发（MinIO）和线上用同一份代码。
- 代价：
  - 功能比 S3 少，周边工具和教程较少。
  - 有两项需要在实现时验证（见"验证检查点"），验证不通过就写新 ADR 换 S3。

估算（存 100GB，只算存储和流量，未扣免费额度）：每月被看 1TB → R2 约 $1.5，S3+CloudFront 约 $2.3；5TB → 约 $1.5 vs 约 $340；20TB → 约 $1.5 vs 约 $1,600。

## 分阶段费用计划
| 阶段 | 用什么 | 预计费用 | 说明 |
|---|---|---|---|
| 开发（M0–M3） | 本地 MinIO（Docker Compose） | $0 | 不接触任何云服务 |
| 上线与内测（M4–M5，朋友试用） | R2 | 预计 $0 | 在免费额度内（10GB 存储、读写次数远低于额度）。开通 R2 时 Cloudflare 可能要求绑定付款方式，M4 开通时确认 |
| 公开运营 | R2 | 超过 10GB 后按 $0.015/GB·月 | 例：100GB 约 $1.35/月，1TB 约 $15/月；流量不收费 |

费用控制：M4 设置 Cloudflare 账单通知；单用户存储配额和原图尺寸上限（`docs/architecture.md` 第 6 节）限制存储增长。

## 验证检查点
- **M2（照片上传）**：确认 R2 的 presigned URL 能限制上传大小和 content-type（ADR-0001 要求）。做不到 → 写新 ADR（例如改用 S3，或换一种限制方式）。
- **M4（部署上线）**：确认删除保护 / 误删恢复的方案（`docs/architecture.md` 第 6 节要求版本控制或删除保护期）。做不到 → 写新 ADR。
- **M4**：图片通过自定义域名（如 `img.<域名>`）访问，遵守下方"访问控制约定"。
- **M4**：确定删除保护的最长保留期（如 30 天），和"删除即清除"（`docs/architecture.md` 第 6 节）一致，并写进隐私政策。

## 访问控制约定（安全审查后补充，2026-11-22）
1. 上传的原图（`pending`，EXIF 尚未清除）和私有照片**永远不放在公开路径上**，只能用后端鉴权后签发的短时效 GET 签名 URL 访问。
2. 只有"公开且 `ready`"的衍生图（已清除 EXIF 的缩略图、WebP 等）可以走公开的 CDN 域名；具体是分 bucket 还是分前缀、或全部走签名 URL，在 M3 方案中确定。
3. 相册从公开改为私有时，要么相关文件不在公开路径上，要么同时清除 CDN 缓存（purge）；M3 要有测试证明私有照片的直链不可访问。
4. 数据库备份不放在照片 bucket 中（见 ADR-0007）。
5. M2 中 worker 处理前先 `HeadObject` 检查实际大小和类型，超限直接删除并标记 `failed`，不信任客户端声明的值。

## 为了以后能换成 S3 必须遵守的约定
1. 代码只通过 S3 标准 API（boto3）访问对象存储，不使用 Cloudflare 专有 API；endpoint、密钥、bucket 名全部来自配置（环境变量）。
2. 对外的图片地址使用我们自己的域名，不使用服务商的域名，换服务商时分享链接不失效。
3. 数据库只存对象 key，不存完整 URL。
4. 对象存储的调用集中在一个模块里（如 `core/storage.py`），业务代码不直接调用 boto3。

## 切换到 S3 的计划
- **触发条件**（任一成立就写新 ADR 评估）：上面的验证检查点不通过；需要 R2 没有的 S3 功能；R2 价格或条款发生不利变化；系统整体迁到 AWS。
- **步骤**：开 S3 bucket 和 CloudFront → 用 rclone 等工具整桶复制 → 改环境变量里的 endpoint 和密钥 → 把图片域名的 DNS 指向 CloudFront → 核对后停用 R2。业务代码和数据库不需要改动。

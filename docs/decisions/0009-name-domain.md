# ADR-0009：产品名与域名
- 状态：已采纳
- 日期：2026-11-22
- 背景：品牌名会影响域名、仓库名、包名。越早定，后面改名的成本越低；但仓促定名也有风险。目标用户在海外（`docs/charter.md` 2.1），v2/v3 会扩展到攻略和社交。
- 选项：
  - A：现在就确定品牌名，代码、包名、域名都用它 / 仓促；以后改名要改大量代码
  - B：代码名和品牌名分开：代码一直用中性的内部代号，品牌名只出现在配置和前端文案、logo 中；品牌名晚些再定 / 新人需要知道两者不同（写进 README）
- 决定：B。
  1. **内部代号为 `travelapp`**（Logan 确定）。Python 包、Docker Compose 项目名、服务名等使用 `travelapp`；GitHub 仓库名保持 `travel-app`。
  2. 品牌名只出现在一个配置项（如 `SITE_NAME`）和前端文案、logo、法律页面中，代码其他地方不硬编码品牌名。
  3. 品牌名以后再起（Logan 确定）。Claude 建议最晚在 M4 部署前确定，因为部署和邮件发件域名都需要域名。确定时写新 ADR 记录名字和域名。
- 理由：改品牌几乎零成本；名字不阻塞 M0–M3 开发。
- 代价：心仪的域名可能在决定前被别人注册；代码名和品牌名不同，需要在 README 中说明。

- 以后什么情况下重新评估：确定品牌名时写新 ADR（记录名字、域名、商标核查结果）；如果以后要改内部代号，也写新 ADR。

## 起名时参考（Claude 的建议，起名时由 Logan 确认）
- 标准：
  1. 短（10 个字母以内），听一遍能拼对（海外用户为主）。
  2. 不只和"照片"绑定（v2 攻略、v3 社交）。
  3. `.com` 能买到，或有可接受的替代（如 `.app`）。
  4. 没有商标冲突（查 USPTO、EUIPO）。
  5. 不模仿现有大品牌（如 xxx-gram）。
- 域名后缀：优先 `.com`（最主流、最被信任），买不到再考虑 `.app`。
- 注册商：Cloudflare Registrar（按成本价、续费不涨价、免费隐私保护；和 DNS、CDN、R2 统一在 Cloudflare 管理）。购买前核实价格。
- 曾提出的候选方向（均未核查可用性）：Wayframe、Trailframe、Footmark、Postcardly、Stampbook、Roamfolio、Wanderlens。

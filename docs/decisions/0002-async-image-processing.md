# ADR-0002：图片处理异步化 + 状态机
- 状态：已采纳
- 日期：2026-11-10
- 背景：校验、HEIC 转码、清除 EXIF、生成缩略图都比较耗时，放在请求里同步做会让接口变慢，还可能超时。
- 选项：
  - A：在请求中同步处理：简单 / 慢，失败时用户体验差
  - B：交给后台 worker，照片记录用状态机（pending → processing → ready / failed）管理：快、可重试、失败可见 / 多一个队列和 worker 服务
- 决定：B
- 理由：上传接口保持快速响应；失败可以重试；状态清晰，前端可以展示处理进度。
- 代价：多一个 worker 服务需要部署和监控。具体用哪个任务框架见 ADR-0003。

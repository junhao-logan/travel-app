# ADR-0001：照片上传用 presigned URL 直传对象存储
- 状态：已采纳
- 日期：2026-11-10
- 背景：照片文件大（手机原图 5–10MB），如果经过后端中转，会占用后端的带宽和内存，并发上传时尤其明显。
- 选项：
  - A：前端 → 后端 → 对象存储：实现简单 / 后端成为瓶颈，成本高
  - B：后端签发 presigned URL，前端直传：后端轻量、可扩展 / 多一步"完成确认"，需要处理残留文件
- 决定：B
- 理由：图片站的核心负载就是上传流量，不应该让 API 服务器承担。
- 代价：需要 `complete` 接口和定时清理任务；presigned URL 必须限定时效、content-type 和大小。

# 决策记录（ADR）

每条重要决策一个文件：`NNNN-short-title.md`。状态：待定 / 已采纳 / 已废弃。
已采纳的 ADR 不修改内容；改主意时写一条新 ADR，把旧的标记为"已废弃，被 NNNN 取代"。

## 模板
```markdown
# ADR-NNNN：标题
- 状态：待定 / 已采纳 / 已废弃
- 日期：YYYY-MM-DD
- 背景：要解决什么问题
- 选项：
  - A：优点 / 缺点
  - B：优点 / 缺点
- 决定：
- 理由：
- 代价：接受了哪些缺点
```
